# Terminal Internal App

## Purpose
Built-in terminal widget mountable on the NEXUS desktop canvas.

## Tech Stack
- React 19 + TypeScript + Vite

## Folder Layout
```
internal-apps/terminal/
├── frontend/
│   ├── package.json
│   └── src/
│       └── App.tsx
└── backend/
    └── README.md
```

## How to Run
Consumed by `apps/shell/frontend`.

## How to Add a Feature
Add a pseudo-terminal frontend and a backend PTY adapter.

## IPC / API Contracts
None by default.

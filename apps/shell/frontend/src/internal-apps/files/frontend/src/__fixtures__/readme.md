# Fixture workspace

A small, real directory for the Files widget. Everything here ships with the
shell so the viewer works offline.

- `notes.txt` — plain text
- `hello.ts` — safe code
- `dot.png` — an image
- `tone.wav` — a short tone
- `clip.mp4` — a tiny video
- `spec.pdf` — a type with no preview
- `design/` — a folder, so navigation is real

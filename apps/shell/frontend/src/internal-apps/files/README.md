# Files Internal App

## Purpose
Built-in file manager widget mountable on the NEXUS desktop canvas.

## Tech Stack
- React 19 + TypeScript + Vite

## Folder Layout
```
internal-apps/files/
├── frontend/
│   ├── package.json
│   └── src/
│       └── App.tsx
└── backend/
    └── README.md
```

## How to Run
Consumed by `apps/shell/frontend`.

## How to Add a Feature
Add file listing UI and wire up a backend storage adapter.

## IPC / API Contracts
None by default.
